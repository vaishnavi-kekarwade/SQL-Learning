# SQL-Learning
Documenting my SQL learning journey with daily practice queries notes and problem-solving for data analytics preparation.

Daily SQL practice using MySQL Workbench.
Datasets used: moviesdb and awesome chocolates

# Topics Covered

- SELECT, WHERE, GROUP BY, HAVING, ORDER BY
- Aggregate functions (COUNT, SUM, AVG, MAX, MIN)
- JOIN and LEFT JOIN
- IF and CASE WHEN
- Subqueries
- String functions (UPPER, LOWER, LENGTH, CONCAT, TRIM)
- Window functions (RANK, ROW_NUMBER, PARTITION BY)
- Date functions (YEAR, CURDATE, WEEKDAY)
